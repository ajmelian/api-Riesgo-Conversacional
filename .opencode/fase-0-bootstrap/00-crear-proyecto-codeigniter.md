# Tarea 0.0 — Crear proyecto CodeIgniter 4.7

**Dependencias:** ninguna

**Descripción:** Inicializar el esqueleto de CodeIgniter 4 en la raíz del repositorio usando `composer create-project`.

**Criterio de aceptación:**
- [ ] `composer create-project codeigniter4/appstarter .` ejecuta sin errores
- [ ] El directorio `app/` existe con la estructura estándar de CI4
- [ ] El directorio `public/` existe con `index.php` y `.htaccess`
- [ ] El fichero `spark` es ejecutable en la raíz

**Ficheros implicados:**
- `composer.json` (creado por appstarter)
- `app/`, `public/`, `writable/`, `tests/`, `spark`
